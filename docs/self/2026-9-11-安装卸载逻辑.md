一、打包与安装方式概述
打包工具：electron-builder 24.13.3，NSIS 目标，配置文件 electron-builder.json。
安装模式：per-user（perMachine=false），只装当前用户，不需要管理员权限，安装目录 %LOCALAPPDATA%\Programs\NianYiTuo。
安装器类型：assisted（oneClick=false），向导式"下一步"安装，非一键静默安装。
安装产物：release\NianYiTuo Setup 版本号.exe。
卸载入口有两个：安装目录里的 Uninstall NianYiTuo.exe（交互式卸载）；Windows 设置 / 控制面板里的卸载项（注意 electron-builder 会同时写入 QuietUninstallString，设置应用可能走静默卸载，静默模式行为见下文进程检测）。

二、自定义逻辑的位置
所有安装/卸载自定义逻辑集中在 build/installer.nsh，通过 electron-builder 的三个宏注入官方模板：
1. customCheckAppRunning：进程检测，安装器和卸载器共用同一份逻辑。
2. customInstall：预留，当前为空。
3. customUnInstall：卸载时的额外清理。

三、进程检测逻辑（customCheckAppRunning）
检测方式：nsProcess 插件的 nsProcess::FindProcess 检测 NianYiTuo.exe，返回 0 表示进程存在。
两种场景行为不同：
1. 静默模式（静默安装/静默卸载、升级流程）：先 taskkill /f 强杀进程，等待 1.5 秒后重新检测；仍在运行则以错误码 2 退出，中止本次操作。
2. 交互模式（双击 Setup 或 Uninstall.exe）：弹窗提示"NianYiTuo 正在运行中，无法继续"。点「重试」会重新检测进程（先退出程序再点重试即可继续）；点「取消」退出安装/卸载。
注意重试跳转的标点（nyCheckAppRunning）必须放在检测语句之前，否则点重试只会重复弹窗、不会重新检测（这是本次修复的第二个问题）。

四、卸载清理逻辑（customUnInstall）
非升级场景（isUpdated 为假，即正常卸载）时，在系统默认清理之外额外执行：
1. 删除开机自启注册表项 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 NianYiTuo。
2. 删除数据目录 %APPDATA%\NianYiTuo 和 %LOCALAPPDATA%\NianYiTuo。
注意：正常卸载会连带删除用户数据（粘贴记录、设置等），如有需要请先备份；升级安装（isUpdated）不会动数据。

五、踩坑记录（本次排查的关键结论）
1. electron-builder 自带 FIND_PROCESS 宏在 per-user 模式下完全失效。
现象：2.1.3 及之前，程序运行中卸载直接卸掉，无任何提示；安装时的"提醒"其实是别的环节弹的，不是检测逻辑在生效。
根因：该宏 per-user 分支用 nsExec::Exec 执行 tasklist 命令，但命令字符串里写的是 %SYSTEMROOT%、%USERNAME% 字面文本；nsExec 底层 CreateProcess 不展开环境变量，命令根本没执行起来，返回字符串 "error"；后续 ${If} $R0 == 0 永远为假，检测形同虚设。per-machine 模式的分支走 nsProcess 插件，不受影响，所以官方一直没暴露这个问题。
修复：弃用 FIND_PROCESS，直接用 nsProcess 插件（2.1.4）。nsProcess.dll 由 electron-builder 自带（nsis-resources 缓存的 plugins 目录），安装器和卸载器都能正常嵌入使用，已用 mini NSIS 实验验证。
2. 卸载流程里"无法关闭请手动关闭"的弹窗文案是 electron-builder 内置英文默认值，因为其 messages.yml 没有中文条目。尝试用 LangString 覆盖中文文案会触发 NSIS 重复定义 warning，而 electron-builder 把 warning 当致命错误，且其内部 include 顺序不确定，无法稳定覆盖，故决定不改文案，沿用英文提示。
3. NSIS 卸载器是双进程机制：运行时原始进程把自己复制到 %TEMP%\~nsuA.tmp\Au_.exe 后立即退出，真正执行卸载逻辑的是副本进程。脚本化验证时直接运行 Uninstall.exe 后立刻读结果会得到假阴性，bat 里要用 start /wait 加 ping -n N 延时等几秒再取结果。
4. Electron 运行中会锁住安装目录的 exe/dll/asar，强删会留下半残目录；所以检测逻辑必须在删文件之前跑，这也是检测失效时目录删不干净的原因。

六、标准验证步骤
1. 双击 Setup 覆盖安装，确认安装成功、版本信息页面显示正确版本号。
2. 启动 NianYiTuo，打开安装目录双击 Uninstall NianYiTuo.exe，应弹出"正在运行中，无法继续"提示（而不是直接卸载）。
3. 程序没关时点「重试」，应仍然弹窗。
4. 退出程序后点「重试」，应正常完成卸载。
5. 卸载完成后确认：安装目录已清空、自启注册表项已删、数据目录已删。
反向验证：程序运行中直接双击 Setup 安装包，同样应先弹运行中提示。
卸载后重装需到设置里重新开启开机自启。
